Quick start

Get started in four steps

You'll need the plain-text clipping file generated by your Kindle: My Clippings.txt.

01

Find My Clippings.txt

Transfer the file from your Kindle to your Mac. When connected by USB, it is usually in the Kindle's documents folder.

02

Import the file

Open K-Clippings and click “Import Clippings” in the sidebar, or choose “Import My Clippings.txt…” from the menu. Select the file to begin importing.

03

Browse and organize

Choose a book, Favorites, or Tags in the sidebar. Search to find an excerpt. Use an excerpt's action menu to edit it, favorite it, add tags, or export it.

04

Export or back up

Export the current book as TXT, Markdown, or DOCX. K-Clippings backs up the source clipping file during import; you can also back up the database from the app menu.

Tip: If you import the same file again, duplicate excerpts are skipped. If an import fails, make sure you selected a readable My Clippings.txt file. When contacting support, include your macOS version and the steps that reproduce the issue.

Frequently asked questions

Where can I find My Clippings.txt?

Connect your Kindle to your Mac with USB and look in the device's documents folder. The location may vary by device or transfer method.

Will importing the same file create duplicates?

K-Clippings skips excerpts that are already in your library. When the import finishes, the app shows how many items were added and skipped.

How do I export my excerpts?

Use an excerpt's action menu to export one note, or use the menu to export the current book. Available formats are TXT, Markdown, and DOCX.

Which languages are supported?

K-Clippings has Simplified Chinese and English interfaces. You can switch languages in Preferences.

Questions or suggestions?

Email stanleylbc@foxmail.com. Include your macOS version and steps to reproduce a problem so we can investigate more quickly.

Privacy

Privacy information

K-Clippings processes imported clippings on your Mac and stores your books, excerpts, tags, and favorites in the app's local data. The current app does not require an account and does not include a feature that uploads this content to the developer's servers.

When you import a file, K-Clippings saves a backup of the source file locally. You initiate database backups and exports in the app and choose where to save them. If you contact support by email, the information in your message is sent to the developer so we can respond and help resolve the issue.

For privacy questions, contact stanleylbc@foxmail.com.

This information describes the current version of K-Clippings for Mac. If the app's data practices change, this page and the privacy information in App Store Connect should be updated.
